# What Is What In docs/

- `project-map.md` — current repository topology, component ownership, and runnable commands. The live entry map for agents.
- `project-charter.md` — mission, external actors, and expected product shape for the challenge.
- `diagnostics.md` — what to do when a command or runtime boundary fails; failure classification guide.
- `ai-foundation.md` — established AI/model boundaries, deterministic shell, and provider seams.
- `master-plan.md` — deadline-aware implementation sequence, subsystem boundaries, acceptance gates, and task-brief handoff.
- `foundation-plan.md` — historical bootstrap record of foundation decisions; not live guidance.
- `foundation-review.md` — readiness review verdict (READY_WITH_NOTES) with observed verification results.
- `initial-analysis/` — first-pass product and dataset analysis packet; its own `README.md` explains the numbered files.
